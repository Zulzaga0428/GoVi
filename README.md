# GoVi — Өмнөговь ХААЦУ нэгтгэл

Өмнөговь аймгийн Ус цаг уур, орчны шинжилгээний газрын **хөдөө аж ахуйн цаг уурын**
салбарын 14 сумын **арав хоногийн мэдээ**-г цуглуулж, нэгтгэн дүгнэдэг нэг хуудас
вэб хэрэглүүр.

**Амьд хуудас:** https://claude.ai/code/artifact/1b82aedb-211b-4538-a65d-0a042b7eb865

## Юу хийдэг вэ

| Хэсэг | Тайлбар |
|---|---|
| Хугацаа сонголт | Он / сар / арав хоног (I: 1–10, II: 11–20, III: 21–сүүл) |
| Мэдээ оруулах маягт | Сум сонгоод бөглөнө. Өмнө өгсөн мэдээ маягтад буун ирж, засварлах боломжтой |
| Нэгтгэл хүснэгт | 14 сум бүгд эгнээтэй. Мэдээ ирээгүй сум ил тод харагдана. Доод мөрөнд аймгийн дундаж |
| Графикууд | Хур тунадас (олон жилийн дунджийн зураастай), бэлчээрийн ургац |
| Аймгийн тойм | Ирсэн мэдээнээс бичвэр дүгнэлт автоматаар боловсрогдоно, хуулж авах товчтой |
| CSV татах | 14 сумын бүх багана Excel-д нээгдэх файлаар |

## Хамрах 14 сум

Өмнөговь аймаг 15 суутай. Даланзадгад бол аймгийн төв станц бөгөөд нэгтгэлийг
хийдэг тул мэдээ өгөх нэгжид ороогүй. Үлдсэн 14 сум:

Баян-Овоо · Баяндалай · Булган · Гурвантэс · Мандал-Овоо · Манлай · Ноён ·
Номгон · Сэврэй · Ханбогд · Ханхонгор · Хүрмэн · Цогт-Овоо · Цогтцэций

## Хэмждэг үзүүлэлтүүд

**Агаар** — дундаж / хамгийн их / хамгийн бага температур (°C), хур тунадас (мм),
олон жилийн дундаж тунадас (мм), салхины хамгийн их хурд (м/с)

**Хөрс** — чийг % (0–20 см), температур °C (10 см), цасан бүрхүүлийн зузаан (см)

**Бэлчээр** — ургамлын өндөр (см), ургац (ц/га, хатаамал жингээр),
хөгжлийн үе шат, бэлчээрийн нөхцөлийн үнэлгээ, ган / зудын эрсдэл

## Өгөгдлийн бүтэц

Мэдээ нь Artifact-ийн `db` санд хадгалагдана.

```
reports/{YYYY-MM-D}-{soumId}
```

Жишээ баримтын ID: `reports/2026-09-1-khanbogd` (2026 оны 9-р сарын I арав хоног,
Ханбогд сум). Хугацаагаар нь `period` талбараар шүүнэ.

| Талбар | Утга |
|---|---|
| `period`, `year`, `month`, `decade` | Тайлант хугацаа |
| `soum` | Сумын ID |
| `t_avg`, `t_max`, `t_min` | Агаарын температур, °C |
| `precip`, `precip_norm` | Хур тунадас ба олон жилийн дундаж, мм |
| `wind_max` | Салхины хамгийн их хурд, м/с |
| `soil_moist`, `soil_temp` | Хөрсний чийг %, температур °C |
| `snow` | Цасан бүрхүүлийн зузаан, см |
| `plant_h`, `yield_p` | Ургамлын өндөр см, ургац ц/га |
| `phase` | Ургамлын хөгжлийн үе шат |
| `cond` | Бэлчээрийн нөхцөл: `good` \| `warning` \| `serious` \| `critical` |
| `risk` | Ган / зудын эрсдэл: `none` \| `good` \| `warning` \| `critical` |
| `obs`, `note`, `at` | Ажиглагч, тэмдэглэл, оруулсан хугацаа |

## Хуудсыг шинэчлэх

`umnugovi-haacu.html` бол эх файл. Засвар оруулсны дараа **байгаа линк дээр нь**
дахин нийтэлнэ — шинэ линк үүсгэхгүйн тулд артефактын URL-ыг заавал дамжуулна:

```
Artifact(
  file_path = "umnugovi-haacu.html",
  url       = "https://claude.ai/code/artifact/1b82aedb-211b-4538-a65d-0a042b7eb865"
)
```

Файлыг браузерт шууд нээж болно — тэр үед сан ажиллахгүй тул хуудас
«Сантай холбогдоогүй» гэж анхааруулж, зөвхөн харагдах байдлыг шалгах зориулалттай
болно.

## Хандалтын хязгаар

`db` зарласан хуудсыг олон нийтэд задгай хуваалцах боломжгүй — нээж байгаа хүн бүр
эзэмшигчийн Claude байгууллагад нэвтэрсэн гишүүн байх ёстой. Сумын ажиглагчид тэнд
байхгүй бол аймгийн төв дээрх нэг хүн 14 сумын мэдээг маягтаар оруулна; нэгтгэх,
бодох, тойм бичих, Excel гаргах хэсэг нь тэр тохиолдолд ч бүрэн автомат хэвээр.

## Хийгдээгүй

- Сум тус бүрийн **жинхэнэ олон жилийн дундаж тунадас** суулгаагүй — одоогоор
  маягтад гараар оруулна. Утгууд гарвал урьдчилан бөглөж болно.
- Арав хоног хооронд харьцуулах **хандлагын график** алга.
