# GoVi — Өмнөговь ХААЦУ нэгтгэл

Өмнөговь аймгийн Ус цаг уур, орчны шинжилгээний газрын **хөдөө аж ахуйн цаг уурын**
салбарын 14 станцын **10 хоногийн мэдээ**-г цуглуулж, нэгтгэн дүгнэдэг нэг хуудас
вэб хэрэглүүр.

**Амьд хуудас:** https://claude.ai/code/artifact/1b82aedb-211b-4538-a65d-0a042b7eb865

## Юу хийдэг вэ

| Хэсэг | Тайлбар |
|---|---|
| Хугацаа сонголт | Он / сар / 10 хоног (01: 1–10, 02: 11–20, 03: 21–сүүл) |
| Схем зураг | Станцуудын байрлалын зураг. Тунадас → агаарын дундаж → ургац → бүрхэц гэж 7 секунд тутам солигдоно |
| Хурдан горим | 14 станцыг нэг хүснэгтэд дараалуулж бөглөнө. Гар бичмэл маягтын багана дараалалтай ижил |
| Нэг станцын маягт | Дэлгэрэнгүй, нэмэлт үнэлгээтэй |
| Нэгтгэл хүснэгт | 14 станц бүгд эгнээтэй. Мэдээ ирээгүй нь ил харагдана. Доод мөрөнд аймгийн дундаж |
| Графикууд | Хур тунадас (ОЖД-ын зураастай), ургамлын ургац |
| Аймгийн тойм | Ирсэн мэдээнээс бичвэр дүгнэлт автоматаар боловсрогдоно, хуулж авах товчтой |
| CSV татах | Бүх багана Excel-д нээгдэх файлаар |

## Багана — гар бичмэл маягтын дараалалтай ижил

| Бүлэг | Багана |
|---|---|
| **Агаар** | дундаж °C · макс °C · мин °C · 30°-аас их хоног |
| **Хөрс** | дундаж °C · макс °C · мин °C · 40°-аас их хоног |
| **Чийг** | харьцангуй чийг % |
| **Салхи** | их хурд м/с · 10 м/с-ээс их өдөр |
| **Хур тунадас** | хэмжээ мм · тунадастай өдрийн тоо |
| **Ургамал** | өндөр см · бүрхэц % · ургац ц/га |
| **Цас** | зузаан см · бүрхэц балл |

**Нэмэлт** (маягт дээр байхгүй, дүгнэлтэд хэрэглэнэ): олон жилийн дундаж тунадас,
ургамлын хөгжлийн үе шат, бэлчээрийн нөхцөл, ган/зудын эрсдэл.

## ХААЦУС-аас өгөгдөл авах

Одоогийн систем: `192.168.100.30/agro_2020/scripts/agro_800.asp` — **дотоод сүлжээний**
ASP програм. Тайлангийн төрлүүд: 800-80 (цаг уурын үзүүлэлт), 800-81 (хөрсний гүний
температур), 800-82 (агаарын чийг, нарны гийгүүлэлт), 800-83 (цасны зузаан, бүрхэц),
800-93 (цасны нэмэлт). URL хэв маяг: `agro_t.asp?ID=20260801&AID=19&EID=800_80`.

**Анхаар:** `192.168.100.30` бол дотоод сүлжээний хаяг. Railway дээр байрлах энэ сайт
тэр рүү **холбогдох боломжгүй** — API зөвшөөрөл авсан ч гүүр байхгүй. Гарц: ① тэр
системийг гадагш нээх, ② энэ програмыг дотоод сүлжээнд байршуулах, ③ хүн өгөгдлийг зөөх.

**Одоо ажилладаг зам (③):** ХААЦУС-ын хүснэгтийг браузер дээр сонгож `Ctrl+C`, дараа нь
хурдан горимын хүснэгтэд `Ctrl+V`. Хуулсан HTML хүснэгт нь табаар тусгаарлагдсан текст
болдог тул шууд буудаг. Зөвшөөрөл, сүлжээ, API шаардахгүй.

## Хурдан горим — 14 станцыг дараалуулж бөглөх

- <kbd>Tab</kbd> баруун тийш, <kbd>Enter</kbd> доошоо, <kbd>Shift</kbd>+<kbd>Enter</kbd> дээшээ,
  сум товчоор дээш доош. Гар бичмэл маягтыг **баганаар доошоо** бөглөх нь хамгийн хурдан.
- <kbd>Ctrl</kbd>+<kbd>V</kbd> — ХААЦУС эсвэл Excel-ээс блокоор наана. Таслалаар бичсэн
  бутархайг (`4,8`) цэг болгож хүлээж авна.
- Станцын нэрний зүүн талын хөх зураас = мэдээгээ аль хэдийн өгсөн.
- Агаарын дундаж ба тунадас хоёулаа хоосон мөрийг **алгасна**.
- **ОЖД багана** хоосон бол өмнөх оны *ижил сар, ижил 10 хоногийн* утгыг санал болгоно.

## Өгөгдлийн бүтэц

```
reports/{YYYY-MM-D}-{станцын индекс}      жишээ: reports/2026-08-1-385
```

| Талбар | Утга |
|---|---|

| `s_avg`, `s_max`, `s_min`, `s_d40` | Хөрс: дундаж, макс, мин, 40°-аас их хоног |
| `rh` | Харьцангуй чийг, % |
| `w_max`, `w_d10` | Салхи: их хурд м/с, 10 м/с-ээс их өдөр |
| `pr`, `pr_d` | Хур тунадас мм, тунадастай өдрийн тоо |
| `pl_h`, `pl_c`, `pl_y` | Ургамал: өндөр см, бүрхэц %, ургац ц/га |
| `sn_d`, `sn_b` | Цас: зузаан см, бүрхэц балл |
| `pr_norm`, `phase`, `cond`, `risk` | Нэмэлт үнэлгээ |
| `obs`, `note`, `at` | Тоовор хийсэн, тэмдэглэл, оруулсан хугацаа |

## Railway дээр байршуулах

Repo-д Node сервер (`server.js`) багтсан тул Railway автоматаар танина.

**1. Өгөгдлийн сан заавал нэмнэ.** Railway → *New* → *Database* → *PostgreSQL*.
`DATABASE_URL` автоматаар холбогдож, хүснэгтийг сервер өөрөө үүсгэнэ. Сан нэмэхгүй бол
мэдээ `data/reports.json`-д хадгалагдаж, **дахин байршуулах бүрд арилна** — хуудсан дээр
анхааруулга гарна.

**2. Хаалттай болгох.** *Variables* хэсэгт `ACCESS_CODE` нэмнэ. Хуудас нэвтрэх код
асууна. Тохируулаагүй бол линктэй хүн бүр бичиж чадна.

| Хувьсагч | Утга |
|---|---|
| `DATABASE_URL` | PostgreSQL холболт. Railway-гийн Postgres нэмэхэд өөрөө орно |
| `ACCESS_CODE` | Нэвтрэх код. Хоосон бол хуудас нээлттэй |
| `PORT` | Railway өөрөө өгнө |

**Локалд:** `npm install && npm start` → http://localhost:3000

### API

| Хүсэлт | Тайлбар |
|---|---|
| `GET /api/config` | Хадгалалтын горим, код шаардах эсэх |
| `GET /api/reports?period=2026-08-1` | Тухайн 10 хоногийн бүх станцын мэдээ |
| `GET /api/reports?month=8` | ОЖД санал болгоход хэрэглэнэ |
| `PUT /api/reports` | Нэг станцын мэдээ бичих буюу шинэчлэх |
| `GET /healthz` | Амьд эсэхийг шалгах |

Код шаардсан үед бүх `/api/reports` хүсэлт `x-access-code` толгой шаардана. Сервер ирсэн
биетийг мэдэгдэж буй талбаруудаар шүүж, төрлийг нь баталгаажуулна.

## Нэг код, хоёр орчин

Хадгалалт нь `watch` / `save` / `byMonth` гэсэн адаптерын ард:

| Орчин | Хадгалалт |
|---|---|
| Artifact (claude.ai) | `claude.use("db")` — шууд, олон хэрэглэгч зэрэг |
| Сервер (Railway) | `/api/reports` — 20 секунд тутам шинэчилнэ |

Хуудас эхлээд Artifact-ийн санг, олдохгүй бол серверийн API-г шалгана. Аль нь ч байхгүй
бол зөвхөн харагдах горимд орж, тэрийгээ ил хэлнэ. Сервер нь энэ нэг файлыг уншиж бүтэн
HTML баримт болгож ороодог тул хоёр хуулбар үүсэхгүй.

## ⚠️ Газрын зураг нь СХЕМ — бодит хил биш

Станцуудыг **харьцангуй байрлалаар** нь байрлуулсан схем, захиргааны **жинхэнэ хилийн
зураг биш**. Байрлал нь `STATIONS` доторх `pos` талбарт 0–1 координатаар бичигдсэн.

Жинхэнэ хилээр солих бол: GeoJSON-ыг тавьж, `renderMap()` дотор тойргийн оронд `<path>`
зурна. Бусад логик (өнгөний шат, үзүүлэлт солих, тайлбар) хэвээрээ ажиллана.

## Хандалтын хязгаар

Artifact хувилбарыг олон нийтэд задгай хуваалцах боломжгүй — `db` зарласан хуудсыг нээж
байгаа хүн бүр эзэмшигчийн Claude байгууллагад нэвтэрсэн гишүүн байх ёстой.

**Гаднаас нэвтрэх шаардлагатай бол Railway хувилбарыг** ашиглана — энгийн линкээр
нээгдэж, `ACCESS_CODE`-оор хамгаалагдана.

## Хийгдээгүй

- **Landing хуудас** (`/`) — захиалагч, бусад аймагт зориулсан. Ажлын самбар `/app` дээр очно.
- **Хандлага** — 10 хоног хооронд, өнгөрсөн оны мөн үетэй харьцуулах график.
- **Албан ёсны баримт гаргах** (Word/PDF) — тэдний илгээдэг маягтаар.
- **Олон аймгийн бүтэц** — станцын жагсаалтыг тохиргоо болгож, 21 аймагт тавих.
- Сумын жинхэнэ ОЖД тунадасны утга суугаагүй.
